## 稼働ルール

| 項目 | 内容 |
|------|------|
| 稼働日 | 火・水・金・土・日（週5日） |
| 休日 | 月・木 |
| 5月休暇 | 5/14(木)〜5/18(月) 全日稼働なし |
| 5月追加休暇 | 5/22(金) 誕生日・5/23(土) ヘーベル打ち合わせ 稼働なし |
| 1日の作業時間 | 実質5h（12:00〜19:30） |
| 撮影可能日 | 火曜・金曜のみ |
| 週の実質稼働時間 | 約25時間 |

## タイムブロック設計（稼働日）

```
12:00〜14:00  作業ブロック① 最優先タスク（2h）
14:00〜14:15  小休憩
14:15〜15:15  作業ブロック② 最優先タスク（1h）
15:15〜16:15  休憩（1h）
16:15〜17:15  作業ブロック③ サブタスク（1h）
17:15〜18:15  作業ブロック④ サブタスク（1h）
18:15〜18:30  小休憩
18:30〜19:30  作業ブロック⑤ バッファ・返信・連絡対応（1h）
```
