## 最初に、考え方をひとつ変えます

**「デザインで3倍は出るか」ではなく「かのさんが15,300回を出せるテーマはどれか」で考えます。**

倍率は**登録者数が分母**です。同じ動画でも、登録者が少ないほど倍率は上がります。

| チャンネル | 登録者 | 3倍に必要な再生数 |
|---|---:|---:|
| ゼロイチWEBデザイン | 91,000 | 273,000回 |
| あやか⌇海外移住Webデザイナー | 15,800 | 47,400回 |
| **かの** | **5,100** | **15,300回** |

**かのさんのハードルは15,300回です。** これは「デザインジャンルでは無理」と切り捨てる前に確認すべき数字でした。

## かのさんが3倍を出せるテーマ：4つ

証拠の強さ順に並べます。

---

### 第1候補｜応募の実態を確かめる（潜入・検証型）

> **例：【検証】クラウドワークスのデザイン案件に未経験で応募したら、どうなったか**

| | |
|---|---|
| **実測の根拠** | りかこ**9.40倍**（15,894回／1,690人）「クラウドワークスのSNS運用代行案件に応募したら"仕事"ではなく勧誘でした」<br>50代かおり**5.37倍**（282,606回／52,600人）「シール貼り副業って今いくら稼げるの？50代の主婦が**検証してみた**」 |
| **基準④** | **2社で3倍超え。GO寄り**（ただし「潜入」と「検証」で中身は少し違います） |
| **コメントで確認済みの実需** | ★Aの最多いいね**👍34**「初心者歓迎ってついてるものは情報商材の紹介や転職エージェントにつなげられることが多い」<br>**👍21**「応募者が殺到してる中初心者に案件来ないでしょ」<br>別動画**👍3**「全然応募してるのに返事がないんです。悲しい」→ 本人の答えは**「根気勝負」** |
| **かのさんの資産** | 実際にクラウドワークスの現場を知っている／**「営業なしで集客する」がこの質問の答えそのもの** |
| **必要再生数** | りかこさんは**15,894回**で成立。**かのさんの3倍ラインとほぼ同じ。届く水準です** |
| **注意** | **否定タイトルにしない**（`titles.md` のNG）。「〜はやめとけ」ではなく「**応募したらどうなったか**」の報告形にする |
| バケット | 集客導線系 |

**この案がいちばん強い理由**：**視聴数の証拠**と**コメントの実需**の両方が揃っている唯一のテーマです。

## 逆に、3倍が出ないテーマ（かのさんが作れるが）

**作らないほうがいい、という意味ではありません。「当たり狙いの枠で使わない」という意味です。**

| テーマ | 実測 | 判定 |
|---|---|---|
| **LP制作** | 47本を測定。**15,300回を超えたのは2本のみ**（うち1本は15,800人、1本は90,700人のチャンネル）。中央値2,195回 | **3倍は無理。成約狙いの枠へ** |
| **Figma** | 直近1年15本、3倍超え**0本**、平均**0.64倍** | 当たり狙いには使わない |
| **ポートフォリオ** | 直近1年12本、3倍超え**0本**、平均**0.22倍** | 同上 |
| **デザインの基礎・配色** | かのさん自身が1.94倍・0.43倍（どちらも1年前） | 資産の枠 |
| **「作り方」を含むもの** | 直近1年15本、3倍超え**0本**、平均**0.11倍**（全語で最下位） | **タイトルに使わない** |

## まとめ：優先順位

| 順位 | テーマ | 証拠の強さ | かのさんの資産との一致 |
|---|---|---|---|
| **1** | **応募の実態を確かめる（検証型）** | **強**（2社で3倍超え＋コメントの実需） | **強**（チャンネル名の真ん中） |
| **2** | **SNS集客・インスタ収益化の入口** | 中（1社・保留） | **強**（受講生実績が2つある） |
| **3** | **AI×デザインの「やってみた」実演** | 中（1社・保留、ただし絶対再生数が高い） | 中（AI主語は避ける必要あり） |
| **4** | **未経験の在宅ワーク入口** | **強**（6社で再現） | 中（**集客の中身がズレるリスク**） |

## 正直に書いておく限界

| 項目 | 内容 |
|---|---|
| **かのさん規模のデザインチャンネルで15,300回を超えた例は、測った範囲に1本もありません** | あやかさん（15,800人）は6本超えていますが、**かのさんの3倍の規模**です。みすずさん（3,450人）は直近1年の最高が**817回**でした |
| 第2・第3候補は1社のみ | 基準④では**「1本だけ突出＝保留」**の扱いです。再現の証拠がありません |
| 検索の網羅性 | 各テーマ5クエリの上位のみ。**全数ではありません** |
| 登録者数は丸め値 | 1万人以上のチャンネルは倍率に±1%前後の誤差 |

**「このテーマなら3倍が出る」と保証できるデータではありません。**
**「このテーマなら、かのさん規模で15,300回を出した実例がある」という水準です。**

## 制作メモ（確認事項）

- **第1候補を作る場合、実際に応募して確かめる必要があります。**やっていないことを言うと `profile.md` の「捏造禁止」に触れます。**検証する時間が取れるかをご判断ください**
- 第2候補で使う受講生実績（フォロワー1,000人未満でSNS運用代行受注）は、**本人の許諾状況**をご確認ください
- 第3候補は**AI主語をタイトルに置かない**形にする必要があります（`titles.md`）。中身でAIを扱うのは問題ありません
- 第4候補は、かのさんが指摘した**「集客の中身がズレる」問題**が残ります。手段をWebデザインのまま置くことで緩和しますが、消えはしません
