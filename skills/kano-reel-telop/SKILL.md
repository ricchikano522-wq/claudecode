# かの｜リールテロップ編集

撮影済みの縦動画（または既に字幕が焼き込まれた動画）に、かののブランドのテロップ層を重ねて書き出す。
デザインと動きは `assets/template.html` に実装済みなので、**作業の中心は「何秒に何を出すか」を `timeline.js` に書くこと**。

## 最初に読むもの

- `references/design-system.md` … 色・書体・部品・動きと、本人が決めたことの履歴。デザインを変える時・迷った時に読む
- `kano-business-axis` スキル … 言葉を外に出す制作物なので、強調する言葉や見出しの文言を決める前に照らす（金額を主役にしない、など）
- `examples/timeline_trouble3.js` … 完成済みの例（59秒・トラブル3選）。データの書き方はこれを真似る

## 必要なもの

- `ffmpeg` / `ffprobe`、Python3 + numpy、Node + Playwright（Chromium）
- フォントは Google Fonts から読み込む（ネットワークが必要）

## 手順

### 1. 素材を調べる

```bash
ffprobe -v error -show_entries format=duration:stream=codec_type,width,height,r_frame_rate -of default=nw=1 <動画>
bash scripts/contact_sheets.sh <動画> <作業フォルダ>/sheets
```

`overview.png`（全体の流れ）と `cap*.png`（字幕の帯だけを0.5秒刻みで並べた一覧）を見て、話している内容を書き起こす。
元動画に字幕が焼き込まれているかどうかで、次の手順が分かれる。

- **焼き込み字幕あり**：同じ言葉で新しいテロップを作り、元の字幕を覆い隠す。手順2へ
- **字幕なし**：話している内容を本人に確認するか、台本をもらう。手順2は飛ばし、`caps` の元字幕の幅は `0` にする

### 2. 焼き込み字幕の時刻と位置を測る

```bash
python3 -I scripts/detect_captions.py <動画> [帯の上端px] [帯の下端px]
```

- `CHG` が字幕の切り替わり時刻。手順1の一覧と照らして、どの字幕が何秒から何秒かを決める（場面の切り替わりも拾うので、一覧で確かめる）
- `BB` が白い文字の範囲。字幕ごとの横幅（右−左）を `caps` の4番目に入れると、テロップの帯がその幅を必ず覆う
- 字幕の縦位置がテンプレートの想定（元動画1400pxの高さで y≈756〜791、2行なら y≈733〜791）と違う時は、`.pill` / `.pill.two` の `top` を合わせて直す
- 「Point」枠などの囲みは `.panel`（left/right 70px・top 770px・高さ380px以上）で覆う。位置が違えば合わせる
- 黒画面に白文字のつなぎは `.card`（全画面）で覆う

### 3. timeline.js を書く

作業フォルダに `assets/template.html` をコピーし、同じ場所に `timeline.js` を作る。

```js
window.TIMELINE = {
  duration: 59.31,        // 動画の長さ（秒）
  srcWidth: 788,          // 元動画の横幅px（出力は1080×1920に拡大する）
  caps: [                 // 字幕テロップ [開始, 終了, 文言, 元字幕の幅px(なければ0), 2行なら1]
    [6.07, 7.87, 'コーダーに<em>納品直前で飛ばれて</em>', 528],
    [20.77, 22.97, '制作期間が<br><em>半年長引いて</em>しまったことも', 510, 1],
  ],
  titles: [               // 上部の見出し [開始, 終了, 英字ラベル, ラベル, 見出し]
    [6.07, 17.93, 'TROUBLE 01', 'トラブル①', '<em>外注先</em>に飛ばれた'],
  ],
  cards: [                // 章タイトル画面 [開始, 終了, 番号, 日本語, ラベル, [背景色3つ]]
    [5.03, 6.07, '01', '1つ目のトラブル', '外注先に飛ばれた', ['#BBD4C8', '#F5D3B6', '#9EBFC6']],
  ],
  panels: [               // 対策パネル [開始, 2行目が点灯する時刻, 終了, 見出し, [1行目, 2行目]]
    [11.73, 14.03, 16.20, 'トラブル①の対策', ['ココナラなどのサービス経由で依頼', 'デモ課題を納品してもらい<br>技術を確認']],
  ],
  punches: [              // 強調 [開始, 終了, 小さい文字, 大きい文字(HTML)]
    [34.70, 36.20, '相場の', '15<small>分の</small>1'],
  ],
};
```

書く時の考え方：

- **字幕テロップは話している言葉のまま**にする。言い換えると声とずれる。明らかな誤字（例：「見置く」→「身を置く」）だけ直し、直したことを本人に伝える
- **見出しは「今どの話か」が常に分かるように**、話の区切りごとに置く（例：トラブル3選 → ①… → ②… → ③… → 失敗の原因は → 大切なこと）
- 強調キーワードの選び方は `references/design-system.md` §4
- 隣り合う字幕は、前の終了＝次の開始にそろえる（そろっていると帯がなめらかにつながる）
- 本人の肩書きや実績（「5年間在宅で稼ぐデザイナー」など）を新しく足す時は、その動画が本人のものか確かめてから

### 4. 何コマか書き出して確かめる

```bash
node scripts/render_overlay.js <作業フォルダ>/template.html <作業フォルダ>/chk 0 0 1.5,6.1,12.5,21.5
# 元動画に重ねて見る
ffmpeg -y -ss 6.1 -i <動画> -i <作業フォルダ>/chk/check_6.1.png -filter_complex "[0:v]scale=1080:1920[v];[v][1:v]overlay" -frames:v 1 comp.png
```

確かめること：

- 元の字幕・枠が少しもはみ出していないか（字幕の切り替わり直後のコマも見る）
- 2行の字幕が2行になっているか、帯から文字がはみ出していないか
- 見出しやパネルが顔に大きくかぶっていないか
- 切り替わりの瞬間（開始時刻ちょうど・0.1秒後・0.3秒後）で、動きが途中でも元の字幕が隠れているか

### 5. 書き出す

```bash
bash scripts/build.sh <動画> <作業フォルダ> <出力.mp4> [再生速度]
```

- 4並列でテロップ層を書き出して重ねる。60秒で10〜15分ほどかかるので、裏で走らせて待つ
- 再生速度を指定すると、映像・声・テロップの動きがそろって変わる（声の高さは保つ）。本人は前回「少しだけ遅く」で 0.9 を選んだ
- 元動画に音声がない時は、`build.sh` の `[0:a]` の部分を外す

### 6. 渡す

- 完成した動画を送り、変えたところを短く伝える（何をどう覆ったか、直した誤字、強調した言葉）
- **本人の映像を含む動画は、GitHub などに勝手に上げない**。テンプレートや `timeline.js` は保存してよい
- 次に調整しやすいよう、「◯秒あたりの字幕の強調を変えたい」のように言ってもらえば直せると添える

## うまくいかない時

| 症状 | 原因と直し方 |
|---|---|
| 「01」が「OI」に見える | 数字の書体設定。`font-variant-numeric: lining-nums` が効いているか確認 |
| ✦が帯の右下にかたまる | `.pill span` のような広い指定が ✦ の `position:absolute` を上書きしている。子要素の指定を絞る |
| 2行の字幕が1行になる | 帯が flex なので、文言を `<span>` で包む（テンプレートは包み済み） |
| 切り替わりの一瞬だけ元の字幕が見える | 開始時刻が遅い。テンプレートは1コマ手前から出すが、`CHG` の時刻を見直す。帯を小さい状態から出す動きにしていないかも確認 |
| フォントが代わりの書体になる | Google Fonts に届いていない。ネットワークを確認し、`document.fonts.ready` を待ってから書き出す（`render_overlay.js` は待っている） |
