# デザインシステム（かの｜リールテロップ）

かののInstagramフィード投稿（@coco_design022）のトンマナに、ノイズ質感のグラフィックを足したもの。
`assets/template.html` にすべて実装済み。ここは「なぜこうなっているか」と、変えてよい範囲の説明。

## 1. 雰囲気の芯

- くすみカラー × 明朝体 × 細い線と✦ ＝「クリエイティブで洗練された」
- 参考にしたもの：
  - フィード投稿：アイボリーのカード、細い内枠、四隅の✦、「FREELANCE ✦ ——」の英字ラベル、両脇に線が入ったラベル
  - 参考画像：粒子の乗ったグラデーション背景、ざらっとした質感のイラスト
- 反対に、原色・極太ゴシック・白フチ文字は使わない。これは YouTube サムネ用（オレンジ1色・極太＋白フチ）の世界観で、リールとは分けている

## 2. 色

`:root` の変数で管理する。v5 で「彩度を少しだけ濃く」と言われた値が今の基準。

| 変数 | 値 | 使いどころ |
|---|---|---|
| `--ivory` | #FBF8F3 | テロップ・カード・パネルの地 |
| `--ivory2` | #F3ECE3 | ラベルの地 |
| `--slate` | #3B3F42 | 文字の基本色 |
| `--rose` | #BA685C | 見出しのキーワード・番号・✦ |
| キーワード色 | #B5513F | 字幕テロップの強調文字（`.pill em`） |
| マーカー | rgba(243,178,140,.6) | 強調文字の下に引く線 |
| `--sage` / `--blue` / `--peach` / `--terra` | #8DB0A5 / #97B5C7 / #F3B892 / #C9805A | タイトル画面の背景のにじみ・イラスト |

- タイトル画面の背景は、3色の大きな円をぼかして重ね、粒子を2枚重ねる。トラブルごとに組み合わせを変えると単調にならない（`cards` の4番目の引数）
- 赤・黄色の原色は使わない。煽り感が出る（ビジネスの軸 §4）

## 3. 書体

| 用途 | 書体 | 備考 |
|---|---|---|
| メインコピー（見出し・タイトル・強調） | しっぽり明朝 B1（800） | Google Fonts |
| 本文（字幕テロップ・パネル） | Yu Gothic → 無ければ Zen Kaku Gothic New（700） | 本人の希望は「游ゴシック体 or セザンヌ」。どちらもこの環境に無いので Zen Kaku Gothic New で代用している |
| 英字ラベル・番号 | Cormorant Garamond | 数字は `lining-nums`（そうしないと「01」が「OI」に見える） |

セザンヌ（FONTWORKS・有料）を使いたいと言われたら、フォントファイルを受け取って `@font-face` で読み込むか、Canva 側で差し替えてもらう。

## 4. 部品（5種類）

**見出しと字幕テロップのデザインには、はっきり差をつける**（本人の指示）。見出しは枠あり、字幕テロップは枠なし。

| 部品 | データ | 見た目 |
|---|---|---|
| 字幕テロップ `.pill` | `caps` | アイボリーの角丸の帯（半径56px）。**枠も✦も付けない**。粒子だけ薄く乗せる。キーワードは `<em>` で囲む → 色＋少し大きく＋マーカー |
| 上部の見出し `.title` | `titles` | アイボリーのカードに細い内枠＋四隅の✦。英字ラベル（線つき）→ ラベル「✦ トラブル① ✦」→ 明朝の見出し。見出しのキーワードは `<em>` でローズ色 |
| 対策パネル `.panel` | `panels` | 見出しと同じ枠つきカード。番号は Cormorant の斜体。行の区切りは点線。2行目は先に薄く出して、話題が移ったら点灯 |
| タイトル画面 `.card` | `cards` | 全画面。ノイズグラデーション背景＋「Trouble」「01」＋明朝の日本語＋ラベル＋ざらっとしたイラスト（ノートPC・マグ・葉・丸） |
| 強調 `.punch` | `punches` | ノイズの乗ったピーチ色の円＋明朝の大きい文字。1本の動画で1〜2回まで |

### 字幕テロップに入れる強調キーワードの選び方

- 1つの字幕につき1か所まで。その字幕の「意味の芯」になる言葉（例：「納品直前で飛ばれて」「責任は全て自分」）
- 接続の字幕（「などすることで」「っていう風に思ってても」）には付けない
- 金額は強調しない（ビジネスの軸「金額を主役にしたコピーを使わない」）。本人が希望したら付ける

## 5. 動き

「テロップが急に出てくる」と言われて追加した。速さは今の値が基準。

| 部品 | 入り方 |
|---|---|
| 字幕テロップ | 帯は1コマ目から出して、5.5%大きい状態からふわっと縮む → 文字が1文字ずつ下から浮き上がる（0.022秒間隔）→ キーワードのマーカーが左から右へ引かれる。続けて切り替わる時は、前の帯より小さくなる場合だけ幅・高さをなめらかに縮める |
| 見出し | 上から降りてくる → 英字ラベルの線が伸びる → ラベルが出る → 見出しが1文字ずつ。終わる0.3秒前から上へ消える。✦はゆっくりまたたく |
| 対策パネル | 板は1コマ目から（4%大きい状態から縮む）→ ラベル → 1行目が左からすべり込み、番号がはずむ → 2行目は薄く出て、指定時刻に点灯 |
| タイトル画面 | 背景のにじみがゆっくり揺れる → 線が伸びる → 「Trouble」→ 数字がはずむ → 日本語が1文字ずつ → ラベル → イラストが下から上がる |
| 強調 | 円がはずんで広がる → 文字が順に出る → 最後の0.25秒で消える |

**元の字幕を隠す部品（字幕テロップ・パネル・タイトル画面）は、下地を小さい状態から出してはいけない。** 縮む途中で元の字幕がはみ出して見えるため、「大きめ→ちょうど」の向きにしか動かさない。
