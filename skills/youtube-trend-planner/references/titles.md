# タイトル・サムネ文言の作り方

## 伸びるタイトルの型（掛け合わせるほど強い）

| 要素 | 具体例 |
|---|---|
| **視聴者主語** | 「未経験から〜できる」「あなたが〜になる」 |
| **等身大の数字** | 月30万／単価30万／月10万／単価15万 |
| **低ハードル** | 未経験・センス0・コード不要・フォロワー1,000人未満 |
| **リスト** | ◯選／◯STEP |
| **手段明確** | Webデザイン／SNS集客 |
| **フォーマット** | 全手順／すべて見せます／これ1本で完結 |

### 勝ち言い回し（実測で強い）

**「叶えた」／「全手順」／「すべて見せます」／「これ1本で」**

### 型の組み立て例

```
【全手順】未経験から〇〇できるようになる3STEP｜Webデザイン×SNS集客
【すべて見せます】コードが書けなくても単価30万の〇〇｜未経験・センス0からでもできる
【これ1本で】〇〇の作り方3STEP｜未経験から「〇〇」になる全手順
```

---

## 避けるもの（実測で沈む）

- **否定タイトル**（「〜はやめとけ」「〜する人の特徴」など）
- **発信者主語**（「私が〜した話」）
- **巨大数字**（月100万など。※自分の実績として本文中に触れるのは可）
- **誇張**（一択・最強・失敗しない）
- **絵文字**（🕊️付きは沈んだ実績あり）
- **AIを主語・枕詞にしたテーマ**（実測で全滅。データとして本文で触れるのは可）

## サムネイル（**文言のみ決定する**。画像はChatGPTに依頼）

### 構成（4要素）

1. **吹き出しキッカー**（上部・小さめ）— 視聴者の痛みを一言で
2. **メインコピー**（中央・最大サイズ・2行）— タイトルの核を短く
3. **四隅ラベル**（角丸・小さめ）— 未経験／センス0／コード不要／全手順 など
4. **右端の縦書きバッジ** — 帯状に1語

### トンマナ（固定）

- **背景**：実写（自宅デスク／暖色ベージュ〜ブラウン）。人物は入れない（後から合成）
- **アクセント色**：**オレンジ1色に統一**。他の原色は使わない
- **フォント**：**極太ゴシック＋白フチ（太め）**＋わずかなドロップシャドウ
- 文字の可読性を最優先し、背景は少し暗く落とす

## ChatGPT（画像生成）用 依頼文テンプレ

`〔 〕` を埋めて使う。

```
YouTubeサムネイル（16:9・1280x720）を作ってください。

【背景】実写の〔自宅デスク／在宅ワークスペース〕。木目のデスク、〔ノートPC・タブレット等〕、
〔小物〕、暖色の間接照明。ベージュ〜ブラウンの暖色トーンで統一し、全体を少し暗く落として
文字の可読性を最優先にしてください。人物は入れません（後から実写を合成します）。

【カラー】アクセントは統一したオレンジ1色のみ。他の原色は使わないでください。

【文字】すべて極太ゴシック体＋白フチ（太め）＋わずかなドロップシャドウ。
- 上部に吹き出し型キッカー：「〔キッカー〕」（白地の吹き出しにオレンジ文字）
- 中央に最大サイズのメインコピー2行：
  1行目「〔メイン1行目〕」（〔強調語〕だけオレンジ文字で一段大きく）
  2行目「〔メイン2行目〕」（白文字）
- 四隅に角丸ラベル（オレンジ地に白文字）：
  左上「〔ラベル〕」／右上「〔ラベル〕」／左下「〔ラベル〕」／右下「〔ラベル〕」
- 右端に縦書きの帯バッジ（オレンジ地・白の極太文字）：「〔バッジ〕」

【禁止】絵文字、青系・紫系の配色、細いフォント、英語のキャッチコピー。
【重要】日本語のテキストは崩さず、正確にこのまま表示してください。
```

> 実際のデスク写真を使う場合は、【背景】を「添付した写真を背景に使ってください」に差し替える。

## レポートへの載せ方

テーマごとに次をセットで出す。

1. **採用タイトル**（1本）
2. **代替案**（3本）
3. **サムネ文言**（キッカー／メイン2行／四隅ラベル4つ／縦書きバッジ）
4. **ChatGPT用 依頼文**（コードブロックでそのままコピーできる形）
