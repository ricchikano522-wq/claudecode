# 台本フォーマット（フル原稿）

## 尺と分量

- **1本20〜30分**
- **本文 8,500〜10,000字**（日本語・話し言葉で約300〜350字/分）
- **尺を水増ししない。** 実例・失敗談・数字・**反論の先回り**（「〜って思いますよね」）で厚くする

---

## 構成（この順番を厳守）

| # | セクション | 中身 |
|---|---|---|
| 1 | **フック** | 同じスキルなのに結果が違う2者を対比 → 「差は〇〇ではない」と言い切る |
| 2 | **共感・過去の自分** | どん底エピソード（1万円のLP／修正20回超／借金30万など）。当時の1日を具体的に |
| 3 | **結論先出し ＋ 誤解2つ** | 開始30秒以内に3STEPの中身を全部言い切る。そのうえで、よくある誤解を2つ先に潰す |
| 4 | **STEP1／STEP2／STEP3** | 各パートを**「予告 → 本論 → 一言まとめ」**の3層で書く |
| 5 | **まとめ ＋ 最初の一歩** | 今日やることを**1つだけ**。5分で終わる粒度にする |
| 6 | **特典CTA** | `references/profile.md` のCTA。押し売りしない |
| 7 | **締めの定型文** | 一字一句この通り（下記） |
| 8 | **制作メモ** | 確認事項を箇条書き。※これは本文ではない |

### 各STEPの3層構造

```
（予告）  このSTEPで何をするのかを1〜2文で。なぜここが効くのかも一言。
（本論）  例え話 → 具体的な手順 → 反論の先回り → 受講生の実例 → 外部データ
（一言まとめ）「〇〇は△△ではなく、□□です。」の形で1文にする
```

> **一言まとめはそのまま30〜45秒のショートになる。**必ず1文で言い切る。

---

## 文体ルール（絶対厳守）

### 必須

- **話し言葉のフル原稿。**ナレーションとして読み上げられる形にする
- **一人称は必ず「私」**（僕・俺は禁止）
- 語尾は **「〜なんですよね／〜なんです／〜だと思いませんか？／〜です・ます／〜ですよね」** で回す
- **同じ語尾を3回以上連続させない**

### 禁止（機械チェックで弾かれる）

| # | 禁止事項 | 例 |
|---|---|---|
| 1 | **文末が「よ」で終わる** | ✗ 〜なんですよ／〜ますよ／〜ですよ　※「〜ですよね」は末尾が「ね」なのでOK |
| 2 | **体言止め・言い切らない文** | ✗ 「〜という話。」「行動。」「また戻して。」「「もう無理だ」と。」 |
| 3 | **本文中の絵文字** | ✗ 🎉 ✨ 🕊️ |
| 4 | **禁止語** | ✗ 主婦／ママ／一択／最強／失敗しない |
| 5 | **AIを主語・枕詞にする** | ✗ 「AIで単価を上げる」　※データとして触れるのは可 |
| 6 | **巨大数字の煽り** | ✗ 「月100万稼げます」　※自分の実績として触れるのは可 |
| 7 | **会社員という立場の否定** | 否定するのは「縛られる働き方」だけ |

### 書式

- 見出しは Markdown（`## フック` など）で付けてよい
- 本文は完全な話し言葉。ト書きは **`（間を置く）` 程度**に留める
- 数字を引くときは **調査名・時期・サンプル数**まで口頭で言う
  （例：「マイナビさんが2025年8月に1,000名に対して行った調査では〜」）

## 締めの定型文（一字一句この通り。改変禁止）

```
今日も最後まで見てくださって、ありがとうございました。また次の動画でお会いしましょう。かのでした。
```

---

## 制作メモ（本文の後に必ず付ける）

次を箇条書きで列挙する。

- 台本内で**断定を避けた点**
- **話者本人にしか確認できない事項**（受講生の詳細、外注費の実額、ノーコードの具体ツール名、
  契約書の条項、LINE特典のキーワード文言など）
- 使用した**例え話**と**外部データの出典・時点**

## 書き終えたら必ず

```bash
python3 scripts/check_style.py 台本_*.md
```

**致命（E）が0件になるまで直す。**
生成直後は「同一語尾3連続」と「引用中止形（「〜」と。）」が高確率で出るので、1回で通ると思わないこと。
