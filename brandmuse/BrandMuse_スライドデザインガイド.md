# BrandMuse Program｜スライドデザインガイド

序章スライドを基準として、講座全体のトンマナを定義したもの。
今後のスライド制作は、すべてこのガイドに準拠する。

> ※ Claude Code にスライド md を作らせる際、このガイドも一緒に渡すこと。

---

## 0. 世界観のキーワード

**静か・上質・柔らかい・余白・物語性**

- 講座の世界観：「あなたの物語を、ブランドにする」
- 台本のトーン：本質シンプル型（静かに芯を通す）
- ターゲット：30代前後の女性（一人事業主）

→ 押し付けがましくない、寄り添うような佇まい。押し売り感・情報過多は厳禁。

## 2. カラーパレット

| 用途 | 色 | 備考 |
| --- | --- | --- |
| 見出し文字 | ネイビー（濃紺） | 明朝体で使用。上品で芯のある印象 |
| 本文文字 | チャコール／ダークグレー | ゴシック体。読みやすさ重視 |
| アクセント① | オリーブグリーン | 番号バッジ、枠線、区切り線 |
| アクセント② | ブルー（くすみ系） | 番号バッジ、枠線（2つ目の要素に） |
| アクセント③ | オレンジ（テラコッタ系） | 番号バッジ、枠線（3つ目の要素に）、強調文 |
| 装飾線 | ゴールド／ベージュ系 | 見出し下の区切り線 |

### 使い分けのルール

- 要素が2つ → グリーン＋ブルー
- 要素が3つ → グリーン＋ブルー＋オレンジ
- 特に伝えたい一文 → オレンジで強調（例：「本当に欲しかったのは…」）

## 4. イラストのトンマナ（最重要）

**画風：水彩画風・淡い彩色・繊細な線画**

- 彩度は低め。淡く、やわらかい。にじみやぼかしを活かす
- 線は細く、繊細に
- 色数は抑える（グリーン、ブルー、ベージュ、淡いオレンジが基調）
- 白場を活かす。塗りつぶさない

### 人物の描き方

- 30代前後の女性。ナチュラルで上品な服装（白シャツ、カーディガン、ワンピースなど）
- 髪はまとめ髪（お団子・シニヨン）が基調
- 後ろ姿・横顔が多い（顔をはっきり描きすぎない。見る人が自分を重ねられるように）
- 表情は穏やか。悩む場面でも、深刻すぎない

### モチーフの例（序章で使用したもの）

- コンパス（羅針盤）／鏡／旗／道・分かれ道／地図・ピン
- 植物（葉・小花・ドライフラワー風）／コーヒーカップ／カレンダー／窓辺
- 風景（丘・道・街並み・草原）

### 避けるもの

- 濃い色・原色・ベタ塗り
- 写実的すぎる描写
- ポップ・かわいすぎる画風
- 情報量の多い背景

## 5. レイアウトの構成要素

### 角丸カード

- 要素を区切るときは、**角丸の枠（ボーダー）** で囲む
- 枠線の色は、アクセントカラー（グリーン／ブルー／オレンジ）
- 背景は、ごく薄い色 or 白

### 番号バッジ

- ①②③ または 01 / 02 / 03
- 丸型のバッジ。アクセントカラーで塗り、白抜き文字

### 区切り線

- 見出しの下に、細い装飾線（ゴールド／ベージュ系）
- 中央に小さな装飾（点や小さな葉のモチーフ）を入れる

### 対比の見せ方

- 左右に並べて対置する（例：「なり方」↔「在り方」）
- 中央に「↔」や「→」を置いて、関係性を示す

---

## 6. 文字量のルール（厳守）

- 見出し：1行（10〜15文字程度）
- 本文要素：3つ以内。各1〜3行（1行あたり15〜25文字程度）
- 1スライド＝1メッセージ
  - 例：「やってはいけない6つ」なら、6つを1枚に詰めず、1つずつ1枚に
- 強調文：1文のみ。オレンジで、スライド下部に配置

| No | パターン名 | 序章での例 |
| --- | --- | --- |


## 9. 序章スライドで確立した「型」（参考）

1. **表紙**：章タイトル（明朝・大）／区切り線／サブタイトル／右下に人物イラスト
2. **2要素の提示**：左右の角丸カード。各カードに番号バッジ＋見出し＋本文＋イラスト
3. **3要素の提示**：3つの角丸カードを横並び。各カードに番号バッジ＋短文＋イラスト
4. **対比**：左右のカードで対置。中央に「→」
5. **実例**：左に文章（3ブロック程度）、右に大きめのイラスト
6. **キーメッセージ**：中央に大きく見出し（2行可）＋補足＋オレンジの強調文＋下部に横長イラスト
7. **まとめ**：番号付きで要点を列挙＋右にイラスト＋下部に補足文

## 10. 制作時のチェックリスト

- [ ] 文字を詰め込んでいないか（一瞬で読めるか）
- [ ] イラストの画風が統一されているか（水彩・淡い・繊細）
- [ ] 色が増えすぎていないか（アクセントは3色まで）
- [ ] 余白が十分にあるか
- [ ] 「静か・上質・柔らかい」という世界観から外れていないか
- [ ] 強調文はオレンジで、1スライド1文までか
