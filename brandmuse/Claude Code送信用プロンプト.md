# Claude Code 送信用プロンプト｜BrandMuse Program 講座スライド生成

以下を Claude Code にそのまま貼り付けてください。

> ※ 台本ファイル（.md）は、あらかじめ Claude Code の作業ディレクトリに置いておく想定です。

## 【ここからコピー】

BrandMuse Program（オンライン講座）の教材スライドを作成したい。
台本（.md ファイル）を渡すので、それをもとにスライド用の md ファイルを生成してほしい。
まずは以下の仕様を理解した上で、指定した台本1本分のスライド md を作成して。

### 1. 講座の概要（世界観を理解するため）

- 講座名：BrandMuse Program
- 講座の芯：時間を切り売りする働き方から、"あなただから"と選ばれる自分のサービスを持つ人へ
- 世界観：「あなたの物語を、ブランドにする」
- ターゲット：30代前後・一人事業主（デザイナー／ライター／動画編集者など）。女性が中心
- 講座のトーン：本質シンプル型（静かに芯を通す）。押し売りせず、寄り添う。女性に好まれる柔らかい言葉選び

### 2. スライドの前提条件（最重要）

- サイズ：16:9
- 用途：受講生が「動画を見ながら」見るスライド。講師が話す横に表示される補助資料
  - → じっくり読む資料ではない。一瞬で認識できる情報量にすること
  - → 話の邪魔をしない。文字を詰め込まない
- 文字量の基準（厳守）：
  - 見出し：1行（10〜15文字程度）
  - 本文要素：3つ以内。各1行（15〜25文字程度）
  - 文章にしない。キーワード or 短いフレーズで
- イラスト：全ページにイラストが入る（各スライドごとに ChatGPT で画像生成する）
  - → 各スライドに「ChatGPT にそのまま渡せる画像生成プロンプト」を必ず含めること
  - → 画面の3〜4割をイラストが占める前提で、文字量を設計する
  - → **絵柄・配色・書体・レイアウトの仕様は、別途共有する「BrandMuse_スライドデザインガイド.md」に準拠すること。** 必ず読み込んでから作業を始めてください
- 原則：1スライド＝1メッセージ
  - 例：「やってはいけない6つ」なら、6つを1枚に詰めず、1つずつ1枚に分ける

### 3. レイアウトパターン（10種類）

各スライドには、必ず以下のいずれかのレイアウトを指定すること。

| No | パターン名 | 用途 | 構成要素 |
| --- | --- | --- | --- |
| 1 | 表紙 | 章・動画の冒頭 | 章タイトル／サブタイトル／講座名 |
| 2 | 扉（ゴール提示） | この動画で何を得るか | 「この動画のゴール」＋一文 |
| 3 | 見出し＋本文 | 基本形。最も多用 | 見出し1行＋要素1〜3個 |
| 4 | 箇条書き | 列挙（ただし1枚1項目が原則） | 見出し＋項目（3つ以内） |
| 5 | 図解・フロー | 動線・手順・流れ | 矢印やステップで構成 |
| 6 | まとめ・締め | ブロックや動画の終わり | 要点の再掲（3つ以内） |
| 7 | 実例・体験談 | 講師の失敗談・事例 | 「私の場合」と分かる見せ方 |
| 8 | ワーク・問いかけ | 受講生に考えさせる | 問い＋記入を促す |
| 9 | 強調・キーメッセージ | 1文だけ大きく見せる | 短い一文のみ（装飾的に） |
| 10 | 比較・対比 | 2つを並べる | 左右 or 上下に対比（NG↔正解、A↔B など） |

### 4. 出力フォーマット

以下の形式で、スライド md を出力してください。

```markdown
# [動画タイトル]｜スライド

---

## Slide 1
- **レイアウト**：1（表紙）
- **見出し**：[テキスト]
- **サブ**：[テキスト]
- **画像生成プロンプト**：[ChatGPT にそのまま渡せる形で。共有された参考画像の絵柄に沿って。例：静かに佇む女性、…]
- **話者メモ**：[この時、台本のどの部分を話しているか。台本の該当箇所を簡潔に]

---

## Slide 2
- **レイアウト**：3（見出し＋本文）
- **見出し**：[テキスト]
- **要素**：
  - [テキスト（15〜25字）]
  - [テキスト（15〜25字）]
- **画像生成プロンプト**：[テキスト]
- **話者メモ**：[テキスト]

---

（以下、同様に続く）
```

### 5. 作成時のルール

1. 台本の流れに忠実に。ブロックごとにスライドを作る。勝手に順番を変えない
2. 文字量を厳守。長くなりそうなら、スライドを分ける
3. 「話者メモ」を必ず入れる。台本のどこを話しているかが分かるように
4. 画像生成プロンプトは具体的に。ChatGPT にそのまま貼って画像が生成できるレベルで書く（例：「悩む表情で頬杖をつく女性、シンプルな線画、余白多め」）。共有された参考画像の絵柄に必ず沿わせること
5. 1スライド＝1メッセージ。詰め込まない
6. 専門用語や難しい言い回しは、スライド上ではやさしく言い換える
7. スライドの枚数は気にしなくてよい。軽いスライドを多く、が正解

### 6. 最初のタスク

まず、以下のファイルを読み込んで、スライド md を作成してください。

```
[ここに台本ファイル名を指定：例）第1章_マインドセット動画_台本.md]
```

出力先： `slides/[台本名]_スライド.md`

作成後、私が内容を確認します。問題なければ、他の台本も同じ形式で作成していきます。

## 補足（あなた用メモ）

### Claude Code に送る前にやること

- 絵柄の参考画像を用意して、Claude Code に直接渡す（このプロンプトと一緒に共有）
  - → Claude Code がその絵柄を踏まえて、各スライドの画像生成プロンプトを書いてくれる

### この後の流れ

1. 参考画像＋このプロンプトを Claude Code に渡す
2. 台本1本分のスライド md を作成 → 内容を確認（イメージと違えばプロンプト調整）
3. 問題なければ、全台本分を作成
4. 各スライドの「画像生成プロンプト」を ChatGPT に渡して、イラストを生成
5. Canva 等でスライドを組む（イラストを配置）

### まだ決まっていないこと

- スライドの配色・書体（絵柄が決まってから）
