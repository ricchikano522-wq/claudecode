# BrandMuse Program｜講座スライド生成システム

オンライン講座「BrandMuse Program」の教材スライドを、**台本（.md）から Claude Code で半自動生成**するための仕組みです。

## 世界観

- 講座の芯：時間を切り売りする働き方から、"あなただから"と選ばれる自分のサービスを持つ人へ
- 世界観：「あなたの物語を、ブランドにする」
- ターゲット：30代前後・一人事業主（女性中心）
- トーン：本質シンプル型（静かに芯を通す）／静か・上質・柔らかい・余白・物語性

## ディレクトリ構成

```
brandmuse/
├── README.md                          … このファイル
├── Claude Code送信用プロンプト.md       … Claude Code に貼り付ける仕様＋依頼文
├── BrandMuse_スライドデザインガイド.md   … 絵柄・配色・書体・レイアウトの基準（必読）
├── 台本/                               … 元となる講座台本（.md）を置く
└── slides/                            … 生成されたスライド md の出力先
```

## 使い方（ワークフロー）

1. **台本を用意する** — 講座の台本を `台本/` に `.md` で置く（例：`第1章_マインドセット動画_台本.md`）
2. **参考画像を用意する** — 絵柄の参考画像を Claude Code に直接渡す（デザインガイドの水彩トンマナに沿ったもの）
3. **Claude Code に依頼する** — `Claude Code送信用プロンプト.md` の【ここからコピー〜ここまでコピー】を貼り付け、`BrandMuse_スライドデザインガイド.md` も一緒に読ませ、対象の台本ファイル名を指定する
4. **スライド md を確認する** — `slides/[台本名]_スライド.md` が生成される。イメージと違えばプロンプトを調整
5. **イラストを生成する** — 各スライドの「画像生成プロンプト」を ChatGPT に渡して画像生成
6. **スライドを組む** — Canva 等でイラストを配置して仕上げる

## 制作の鉄則

- **1スライド＝1メッセージ**（詰め込まない）
- 見出しは1行（10〜15文字）、本文要素は3つ以内・各1行（15〜25文字）
- 文章にしない。キーワード／短いフレーズで
- 全ページにイラスト（画面の3〜4割）。画像生成プロンプトを必ず添える
- アクセントカラーは3色まで（グリーン／ブルー／オレンジ）
- 強調文はオレンジで、1スライド1文まで

詳細な基準は [`BrandMuse_スライドデザインガイド.md`](./BrandMuse_スライドデザインガイド.md) を参照。
